# Telegram Reminder Bot (Pyrogram)

Бот-напоминалка для Telegram-канала с подтверждением событий.

## Возможности
- Добавление событий `Название + время HH:MM`.
- События отправляются в канал и требуют подтверждения.
- Если не подтверждать, бот шлёт повтор каждую минуту.
- После подтверждения событие не удаляется, а планируется на следующий день в то же время.
- Список событий через кнопки:
  - пагинация `⬅️/➡️`;
  - справа от каждого события кнопка удаления `🗑`;
  - клик по событию открывает редактирование имени/времени.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
Для Termux это особенно важно: `tzdata` нужен для работы `ZoneInfo`.

## Настройка
1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Экспортируйте переменные окружения:
```bash
set -a
source .env
set +a
```
Либо просто оставьте файл `.env` рядом с `bot.py` — бот загрузит его автоматически.

### Важно (частая ошибка)
Нужно использовать **имена переменных**, а не подставлять ваши значения в квадратные скобки в коде.
Правильно:
- `API_ID=38903874`
- `API_HASH=42a484e1eab11d46fe9e9173770292ac`
- `BOT_TOKEN=8690...`

Неправильно:
- `os.environ[\"38903874\"]` ← это ищет переменную с именем `38903874`, которой обычно нет.

### Ошибка `ZoneInfoNotFoundError` (`No module named 'tzdata'`)
Если видите такую ошибку, значит в окружении нет базы таймзон.
Решение:
```bash
pip install tzdata
```
После этого `TIMEZONE=Europe/Moscow` будет работать корректно.

## Запуск
```bash
python bot.py
```

## Команды
- `/start` — открыть меню.
- `/events` — список событий кнопками.
- `/add Название | HH:MM` — быстро добавить событие.

## Права
- Добавьте бота админом в канал, чтобы он мог отправлять сообщения.
- Если `ADMIN_IDS` не задан, управлять ботом сможет любой пользователь в личке.
